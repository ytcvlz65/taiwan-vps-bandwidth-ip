## “不限流量”的真实含义：流量不计量，带宽有封顶

所谓不限流量，指的是一个月内用多少GB都不计费、不封顶，但速率上限是固定的——你买到的是一条固定带宽的线路，跑满带宽就是极限，不存在“不限流量还能无限加速”。各家封顶值不同：ReCloud的台湾Hinet家宽给到600Mbps峰值，HurricaneCloud同样做到600Mbps，PQS的HiNet线路200Mbps起步，丽萨主机的不限流量VDS分100/200/500Mbps三档。
